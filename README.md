# Support Vector Classifier (SVC)

## 📌 Overview
This project implements a Support Vector Classifier (SVC) using Python to solve a supervised classification problem. SVC is a powerful machine learning algorithm that works by finding an optimal hyperplane that separates different classes in the feature space.

The project demonstrates a complete machine learning pipeline, including data preprocessing, feature scaling, model training, evaluation, and interpretation of results. It is developed in Google Colab using Scikit-learn.

---

## 🧰 Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn

---

## 🔍 Project Workflow
1. Data Loading
2. Data Cleaning and Preprocessing
3. Feature Scaling
4. Exploratory Data Analysis (EDA)
5. Model Training using Support Vector Classifier (SVC)
6. Hyperparameter Tuning (Kernel, C, Gamma)
7. Model Evaluation
8. Result Visualization
